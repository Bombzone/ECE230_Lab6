## Summary
In this lab we learned how to make a full adder in Verilog, how to combine full adders, and the importance of XORs in an adder.

## Lab Questions

### 1 - How might you add more than two bits together?
You would combine more full adders together.

### 2 - What is the importance of the XOR gate in an adder?
It is the simplest way to add two bits together.

### 3 - What is the largest number a two bit adder can handle? What happens when you go over?
It can output up to the number 3, if you want to go over the number 3 it will need more bits.
